\section{Problem Formulation}
\label{sec:problem_formulation}

We consider multi-hop legal question answering, where a conclusion may require
connecting statutory conditions, intermediate events, and legal consequences.
Legal knowledge is represented by a directed graph $G=(V,E)$ and a rule set
$\mathcal{R}$. Each node denotes a normalized legal event, while each edge
summarizes one or more condition--consequence rules. The graph supports
retrieval and topological analysis, whereas $\mathcal{R}$ defines the inference
semantics.

Given a question $q$, the system constructs candidate reasoning paths
\begin{equation}
\mathcal{P}(q)=\{P_1,\ldots,P_K\},\qquad
P_i=v_0\xrightarrow{r_1}\cdots\xrightarrow{r_h}v_h,
\end{equation}
and selects
\begin{equation}
P^*=\arg\max_{P_i\in\mathcal{P}(q)}S(P_i,q),
\end{equation}
where $S$ combines semantic and structural relevance.

\subsection{Three-Valued Linear-Algebraic Semantics}

Each event is associated with
\begin{equation}
X_i\in\{1,0,\bot\},
\end{equation}
representing \textsc{true}, \textsc{false}, and \textsc{unknown}. Unknown
denotes missing or conflicting support, not a numeric value between zero and
one. This follows three-valued fixed-point semantics
\cite{kleene1952metamathematics,fitting1985kripke} and its vector-space
extensions \cite{sato2020threevalued}.

The event state is encoded using two support channels:
\begin{equation}
(t_i,f_i)=
\begin{cases}
(1,0), & X_i=1,\\
(0,1), & X_i=0,\\
(0,0), & X_i=\bot.
\end{cases}
\label{eq:two_channel_state}
\end{equation}

Let $n=|V|$ and $p=|\mathcal{R}|$. We define body-incidence matrices
$\mathbf{B}^{+},\mathbf{B}^{-}\in\{0,1\}^{p\times n}$ and head-incidence
matrices $\mathbf{H}^{+},\mathbf{H}^{-}\in\{0,1\}^{n\times p}$. For
$\mathbf{k}=(\mathbf{B}^{+}+\mathbf{B}^{-})\mathbf{1}$, rule bodies and
activations are
\begin{equation}
\mathbf{b}
=
\mathbb{I}
[\mathbf{B}^{+}\mathbf{t}
+\mathbf{B}^{-}\mathbf{f}
=\mathbf{k}],
\qquad
\mathbf{a}
=
\mathbf{b}\odot(\mathbf{1}-\mathbf{e}),
\label{eq:rule_activation}
\end{equation}
where $\mathbf{e}$ indicates active exceptions. Requiring equality with
$\mathbf{k}$ implements conjunction among literals within each rule.

Support for rule heads is aggregated as
\begin{equation}
\mathbf{d}^{+}
=
\mathbb{I}[\mathbf{H}^{+}\mathbf{a}\geq1],
\qquad
\mathbf{d}^{-}
=
\mathbb{I}[\mathbf{H}^{-}\mathbf{a}\geq1].
\label{eq:head_support}
\end{equation}
The threshold implements disjunction across independently activated rules with
the same consequent. Thus, $(A\land B)\rightarrow Y$ is encoded as one rule
with two body entries, whereas $(A\lor B)\rightarrow Y$ is normalized into
$A\rightarrow Y$ and $B\rightarrow Y$. This incidence representation is
related to matrix- and tensor-space logic programming
\cite{sakama2021tensor}.

The factual state is obtained by fixed-point iteration:
\begin{equation}
\mathbf{x}^{F}
=
\operatorname{Fix}
(\Phi_{\mathcal{R}},\mathbf{x}^{(0)}).
\label{eq:factual_fixed_point}
\end{equation}
Positive-only and negative-only support produce true and false states,
respectively; absent or conflicting support produces unknown. The runtime
evaluates sparse rules symbolically rather than performing dense matrix
multiplication. Although the engine supports multi-literal bodies, the current
dataset contains only one positive antecedent per imported rule; conjunction is
therefore not empirically evaluated in this experiment.

\subsection{Topological Diagnostic and Structural Intervention}

Let $\mathcal{M}(P^*)=\{v_1,\ldots,v_{h-1}\}$ be the intermediate events of the
primary path and let $m\in\mathcal{M}(P^*)$. A node-deletion diagnostic forms
\begin{equation}
G^{-m}=G[V\setminus\{m\}]
\end{equation}
and checks
\begin{equation}
\rho_{\mathrm{top}}(s,Y\mid m)
=
\mathbb{I}
[Y\text{ is reachable from }s\text{ in }G^{-m}].
\label{eq:topological_ablation}
\end{equation}
This operation only measures bounded topological reachability and is not used
as the LegalSCM counterfactual definition.

For an explicit mediator-removal query, LegalSCM instead applies the structural
intervention \cite{pearl2009causality}
\begin{equation}
do(X_m=0),\qquad 0\equiv\mathrm{FALSE}.
\end{equation}
The intervention fixes $X_m$ to false and disables every rule that determines
it:
\begin{equation}
\mathcal{R}^{do(X_m=0)}
=
\{r\in\mathcal{R}\mid
\operatorname{var}(\operatorname{head}(r))\neq m\}.
\end{equation}
The counterfactual state is then recomputed as
\begin{equation}
\mathbf{x}^{CF(m)}
=
\operatorname{Fix}\!\left(
\Phi_{\mathcal{R}^{do(X_m=0)}},
\mathbf{x}^{(0)}[X_m\leftarrow0]
\right).
\label{eq:cf_fixed_point}
\end{equation}

Mediator $m$ is necessary for target $Y$ when $x_Y^{F}=1$ and
$x_Y^{CF(m)}=0$, non-necessary when both values are $1$, and indeterminate
otherwise. This is a model-relative structural intervention without exogenous
abduction and must not be equated with deleting $m$ from $G$.

Finally, the system predicts
\begin{equation}
z\in\{
\textsc{supported},
\textsc{reject-direct-claim},
\textsc{uncertain}
\}
\end{equation}
and produces
\begin{equation}
f:(q,G,\mathcal{R})
\rightarrow(P^*,z,\mathcal{E}^*,a,C),
\end{equation}
where $\mathcal{E}^*$ is the verified evidence, $a$ is the answer, and $C$ is
the set of statutory citations.
